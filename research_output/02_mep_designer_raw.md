### 設備設計の後工程問題と他職種との調整の苦労（複数メディアの記事横断）
URL: https://kenchiku-setsubi.biz/setsubisekkei-kitsui/ ほか複数（403のためスニペットより）
書き手: 設備設計経験者・転職コラム執筆者
観点1: 案件で最初に確認すること → 施主の建物利用方法・収容人数・人の流れ、空調冷暖房が必要な箇所と温度調節範囲を最初に把握。意匠設計者とともに確認することが多い
観点2: 設計が進められない条件 → 「意匠設計や構造設計が終わらないと設計に入れない」というのが設備設計の構造的な制約。前工程が遅れるとそのシワ寄せが設備に直撃する。「建築が遅れると設備が泣く」という業界の諺がある（新人研修で教わる）
観点3: 他職種との争点 → 意匠・構造・設備の三者間調整。構造側から「設備の都合で構造体を変更する必要があると突然言われ、全計算と図面を急遽修正しなければならなかった（38歳女性・構造担当）」というエピソード。向こうが"希望的観測"で設計してて、いざ製造するときに問題が判明することが多い
観点4: 設計→運用への跳ね返り → 着工後も建築主との打合せで変更が多発。空調・照明・インターネットはこだわりを持つ建築主が多く、コストへの影響が大きい。変更後の性能とコストをわかりやすく説明して合意形成が必要
観点5: ベテランの教え → 「設計問題は責任分担の境目で起こる。分担が曖昧なところ（特にPS＝パイプスペース周辺）で一番多く起きる」（15年以上の経験者・note記事）

### 天井懐・梁・設備納まりの実務知識（設計者向けブログ記事スニペット）
URL: https://akisho-workshop.com/archives/2214 ほか（403のためスニペットより）
書き手: 設計実務者（設備・建築系ブログ執筆者）
観点1: 案件で最初に確認すること → 階高・天井高さ・梁せい・梁下がり（FLマイナス○○）・防煙垂れ壁の有無。「階高は天井裏の懐を決定する最も重要な要因。設計後半での変更は大変困難」
観点2: 設計が進められない条件 → 「意匠担当が階高もたいしてないのに天井高さを確保しようとするケースがある。設備的視点からその天井高さが無理なら無理とはっきり発言することが重要」。梁スリーブは鉄骨発注前に確定が必須、「現場で鉄骨スリーブを開けなおすことはできない」
観点3: 他職種との争点 → 梁と配管・ダクトの干渉。「小梁なら移動可能だが、大梁は建物の主要構造体のためダクト・配管側で対応するしかない」。衛生配管と梁の干渉は水廻りで多発。FD（防火ダンパー）の点検口について「このFDは点検が難しいが仕方ない」はNG、意匠設計から見栄えを優先されても法的義務があることを突っぱねるのが施工管理者の責務
観点4: 設計→運用への跳ね返り → 「維持管理が困難な天井裏・床下・階間などに設備機器を設置してしまうケースがある。設計当初から機器の置き場（理想は機械室）を想定しておくことが大切」
観点5: ベテランの教え → 天井裏懐有効寸法＝「保温を考慮した配管径＋100mm程度」あれば十分。施工図作成時に干渉チェックが不十分だと現場でダクトをあちこち曲げる事態になる

### 空調方式選定の判断基準（設備設計実務）
URL: https://www.faith-recruit.jp/blog/faith-as/201236 ほか（スニペットより）
書き手: 設備設計者・空調設備専門家
観点1: 案件で最初に確認すること → ヒアリング不足・情報の聞き漏れが後工程のやり直しにつながる最大リスク。建物用途・面積・在室人数・設備の発熱量・換気量が設計条件の根幹。「企画段階でのヒアリングの精度」と「熱負荷計算の正確さ」が空調方式選定の成否を左右する
観点2: 設計が進められない条件 → 熱負荷計算が完了しないと機器台数・仕様が確定しない。換気設計と空調設計はセットで行わないと整合が取れない。「天井高の高い空間は天井カセットでは気流が下まで到達せず"ショートサーキット"になる」ため、空間の高さと方式の整合が取れないと前に進めない
観点3: 他職種との争点 → 「梁のレイアウトや大きさによって配管が通せるかが決まる。梁のレイアウトと配管計画は意匠設計の変更とともに流動的に変わるため、各自が独立して対応していると配管計画が成立しなくなっていることがある」
観点4: 設計→運用への跳ね返り → 「機械が大きいこと・配管の取り回しも大変」という現場代表の発言。老朽化した設備は効率的な冷暖房を妨げるだけでなく、頻繁な故障やメンテナンス手間を増やす原因となる。LCC（ライフサイクルコスト）は建設コストの4倍ともいわれ、その大半が運用コスト
観点5: ベテランの教え → 中央方式は熱源機を1か所に集約できて維持管理が容易。個別方式はフロア単位で制御できて省エネ向き。「空調機械室の床面積＝空調対象床面積×4%」が目安。空調方式は「方式・熱源・用途」の3つに整理して選定するとよい

### 設備設計と構造設計の干渉問題（建設業界実務資料スニペット）
URL: https://www.nikkenren.com/kenchiku/jfcc_setsubi/pointsheet/pdf/all.pdf ほか（403のためスニペットより）
書き手: 日本建設業連合会設備専門部会・設備設計実務者
観点1: 案件で最初に確認すること → 「総合プロット図」を工事初期段階に作成。意匠・構造・設備情報を一元化し、機器配置に対して梁の位置に問題がないか、スリーブ位置も早期確認が必須
観点2: 設計が進められない条件 → 鉄骨プレート梁の貫通はすべて工場で加工されるため、設計時に配管・ダクト等の貫通位置を確定し、構造担当の承認を得ないと前に進めない。「鉄骨発注前にスリーブ位置が構造・外壁パネル等との整合が取れているかを確認しないと、現場での多工種にわたる変更を余儀なくされる」
観点3: 他職種との争点 → 「壁に配管等が埋め込まれる場合には設備設計者と設計段階で協議し、配管径を細くする等の措置が必要（東京都財務局構造設計指針）」。柱・梁への配管埋設は原則禁止。梁貫通孔を設ける場合は適切な補強設計が必要
観点4: 設計→運用への跳ね返り → 「設計者が普段現場を見る機会が少ないせいか、メンテナンス性に優れた構造が考慮されているケースはあまり多くない（MONOist保全連載）」。保全担当者から「メンテナンス性が最悪」という悲痛な訴えが社内に届かないことも多い
観点5: ベテランの教え → 「ある日突然わかった気がする」（ゼネコン設計部・入社数年目社員）。先輩の仕事のやり方を積極的にまねる。「ある程度図面が描けるようになっても現場を想像できなければ、それはあくまで"線"を描いているにすぎない」（設備エンジニアブログ著者）

観点5: ベテランの教え → なし

### 設備設計の実務フロー・最初の確認事項（共同設備企画事務所・コンマガ）
URL: https://kyodo-facilities.co.jp/facility-design-flow/ ほか（403のためスニペットより）
書き手: 設備設計事務所実務者・コラム執筆者
観点1: 案件で最初に確認すること → 建物の利用方法・収容人数・人の流れを把握（意匠設計者と共に）。空調能力に見合う設備機器の配置スペース確保が可能か、採光・照明、光熱費などの維持管理費が高騰しないかも初期段階で確認。設計初期から設備設計者が加わるケースが増加中
観点2: 設計が進められない条件 → 概算時に予算オーバーが見込まれる場合は仕様変更・建築面積縮小・設備中止を検討する必要があるが、「詳細設計後は変更が難しくなるため、概算段階での費用抑制が重要」。機械設備・電気設備の両方が絡まないと全体整合が取れない
観点3: 他職種との争点 → 機械室など音の出る部屋の上下・左右の防音対策・防振を意匠と協議。DS・PS・便所等の上下階との位置関係も意匠と調整。設備機器の位置・形状・メンテナンススペースを意匠と事前協議しないと後から変更困難
観点4: 設計→運用への跳ね返り → LCC（ライフサイクルコスト）は建設コストの4倍ともいわれる。更新しやすい設備機器やシステムを提案して運用コストを最適化することが設備設計の重要な役割
観点5: ベテランの教え → 「施工の納まりや工事手順を想定しながら実施設計図を作成するには幅広い知識と経験が必要。図面に不備があると追加対応やコスト増加の原因になる」
