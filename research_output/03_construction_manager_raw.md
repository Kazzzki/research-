## 視座サマリー

### 判断パターン

施工計画者・現場所長に特有の「Xを見たらYを疑う」条件反射的判断を以下に列挙する。

1. **1/100図面で納まっているように見える → 1/20以下で描き直して干渉を疑う。** 縮尺1/100では線の太さだけで数十mm吸収されるため、梁下クリアランス・配管ルート・ダクトスペースは必ず拡大詳細で検証する。
2. **設計図に施工手順の記載がない → 型枠・足場・揚重のアクセスルートが確保されていないと疑う。** 生身の人間と工具が入れるか、部材搬入経路は確保されているかを即座に確認する。
3. **設計変更が口頭・メモのみで伝達された → 図面と実施工のズレ（=手戻り・追加工事費の温床）を疑う。** 記録なき変更指示は「なかったこと」にされるリスクがあるため、必ず質疑書・設計変更指示書として文書化を求める。
4. **山留め壁の変位量データが計算値を超えた → 周辺地盤沈下・近隣構造物への影響を疑う。** 日次の動態観測値がアクションレベルに達した時点で、施工を止めて対策会議を招集する。
5. **施工図の初回チェックで質疑が少なすぎる → チェック者のスキル不足を疑う。** 施工図作成時に「必ず不具合が発生する」のが前提であり、質疑ゼロは見落としの証拠。
6. **基礎の通り芯・レベル確認を一人で完結している → 基準点の取り間違いを疑う。** ポイントを間違えたまま天端まで施工が進み、コンクリート構造物の取り壊し・再施工に至った事例がある。複数人のクロスチェックが鉄則。
7. **行政許認可・長納期資材の手配状況が工程表に反映されていない → クリティカルパスが管理されていないと疑う。** 自社努力で短縮できない工程こそ最優先で監視する。
8. **設計完了間際に発注者確認がされていない → 着工後の重大設計変更を疑う。** 設計末期の未確認事項は、着工後に「ちゃぶ台返し」となり工期・コスト・品質すべてに波及する。

### 争点マップ

**施工者 vs 意匠設計者**
- 「納まらない図面」の責任所在。意匠設計者は「現場で何とかするのが施工者の仕事」と主張し、施工者は「そもそも1/100で描いた時点で干渉が解消されていない」と反論する。
- 仕上げ材の取り合い・見切り部分の納まり。意匠設計者はデザイン優先で断面詳細を詰めず、施工者は「見栄えのツケを現場に回すな」と感じる。
- メンテナンス性の軽視。天井裏の点検口不足、外壁のゴンドラ設置計画なしなど、「将来の放棄」を施工者が指摘しても意匠側は「竣工時の美しさ」で押し切ろうとする。

**施工者 vs 構造設計者**
- 配筋の過密・施工不能。構造計算上は成立しても、実際に鉄筋が入らない、コンクリートが回らない断面が発生する。施工者は「手が入らない配筋図」を最も嫌う。
- 山留め計画の安全率と経済性のバランス。構造設計者は安全率を高く取りたがるが、施工者は仮設コストと工程への影響を見て「過剰設計」と感じる場面がある。
- 構造スリーブの後入れ問題。構造設計者がスリーブ位置を確定させないまま躯体図が進み、施工段階でコア抜きが発生する。

**施工者 vs 設備設計者/サブコン**
- 天井裏・PSのスペース争奪戦。空調ダクト・配管・電気ケーブルラックが同じ空間を奪い合い、先に施工図を出した者が有利になる「早い者勝ち」構造。施工者（元請）は全体の納まり調整を強いられるが、各サブコンは自工区の都合を優先する。
- 設備スリーブ・インサートの期限遵守。躯体コンクリート打設前にスリーブ図を確定させる必要があるが、設備サブコンの図面提出が遅延し、躯体工程が止まる。
- 試運転調整期間の確保。設備サブコンは「躯体が遅れたから試運転期間を短縮しろ」と言われることを嫌い、施工者は「設備図面の遅延が躯体を遅らせた」と主張する。

**施工者 vs 発注者/CM**
- 設計変更に伴う追加工事費・工期延長の認定。施工者は「変更指示があった以上、費用と工期の補償は当然」と考えるが、発注者/CMは「当初見積に含まれるべき範囲」と値切りにかかる。
- 品質とコストのトレードオフ判断。CMが「VE（バリューエンジニアリング）」と称してスペックを下げようとするとき、施工者は「品質リスクの責任を誰が取るのか」を問う。
- 安全管理コストへの理解不足。QCDSE優先順位で「S（安全）が最優先」は施工者の鉄則だが、発注者/CMが工期短縮・コスト削減を求めるあまり安全対策費を削ろうとする場面が生じる。

### 嗅覚の言語化

現場所長が「この現場はやばい」と感じるシグナルを以下に整理する。

| シグナル | 具体的な兆候 | 現場所長の内心 |
|---|---|---|
| 図面の納まり不良 | 設計図の断面詳細がなく、1/100平面図しか存在しない。質疑を出しても「現場判断で」と返ってくる | 「この設計事務所は逃げている。全部うちが被る」 |
| 設計変更の頻発 | 着工後に週1回以上の設計変更指示が出る。しかも口頭指示が多い | 「記録を取らないと後で全部施工者のせいにされる」 |
| 施工図チェックの質疑ゼロ | 若手が「問題ありません」と報告してくる施工図に質疑が1件もない | 「見ていない。あるいは見る力がない。自分で全部見直すしかない」 |
| 地盤データと設計の不一致 | ボーリングデータと山留め計画の前提地盤条件がずれている | 「地下で何が起きるか読めない。動態観測を増やさないと危ない」 |
| サブコン図面の提出遅延 | 設備スリーブ図の提出が躯体打設2週間前になっても来ない | 「躯体を止めるか、後でコア抜きか、どちらにしても工程が死ぬ」 |
| 発注者の意思決定遅延 | 仕上げ材・設備仕様の決定が予定より1ヶ月以上遅れている | 「長納期品の発注が間に合わない。工期末に地獄を見る」 |
| 安全軽視の空気 | 工期短縮のために仮設計画の簡略化を求められる | 「S→Q→D→Cの順番を崩したら、事故が起きたとき全責任を負うのはうちだ」 |
| 複数業者間の調整不在 | 各サブコンが個別に施工を進め、元請の総合調整会議が機能していない | 「干渉が現場で発覚する。手戻りの嵐になる」 |

### 成長曲線

**若手（1-5年目）**
- 設計図チェックは「寸法の照合」「記載漏れの確認」レベルに留まる。納まりの良し悪しを判断する施工図スキルが未熟。
- 図面の赤入れ・付箋・質疑一覧作成という「手順」を身体に叩き込む時期。手順を踏むこと自体が訓練。
- 失敗（基礎ポイントの取り間違い、レベル確認の見落とし等）を通じて「確認の鉄則」を体得する。失敗経験が最大の教材。
- 地盤変動・工法選定・安全管理の基礎知識を蓄積し、現場での信頼を少しずつ得ていく段階。

**中堅（5-15年目）**
- 「複雑なところ、間違えそうなところ」を図面上で嗅ぎ分けられるようになる。施工図チェックが「寸法照合」から「納まり検証」に質的転換する。
- 複数工種の干渉調整（躯体・設備・仕上げ）を自ら主導できるようになる。サブコンとの調整会議を仕切る力がつく。
- 山留め・仮設計画など、自然相手の不確定要素を含む施工計画を立案し、データ（動態観測値等）に基づく判断ができるようになる。
- 過去の失敗・トラブル事例のデータベースが頭の中に蓄積され、「このパターンは前にも見た」という経験則で先手を打てるようになる。

**ベテラン（15年以上）**
- 図面を見た瞬間に「この現場の急所」がわかる。設計図の行間（描かれていないこと）から問題を予見する能力。
- QCDSE全体を俯瞰し、安全・品質・工期・コストのトレードオフを自分の責任で判断できる。「S→Q→D→Cの順番は崩さない」を組織に徹底させるリーダーシップ。
- 設計者・発注者・サブコンとの争点を予測し、証拠（質疑書・変更指示書・写真記録）を着工前から仕込んでおく「交渉の布石」を打てる。
- 若手の施工図チェック結果を見て、そのチェック者のスキルレベルを瞬時に判定し、必要な教育・フォロー体制を組む。

### CMrへの示唆

**最初に聞くべき質問**
- 「施工図はどの段階まで進んでいますか。質疑は何件出ていますか。」→質疑件数で設計図の完成度と施工者のチェック力の両方がわかる。質疑が異常に少なければ、図面の質が高いのではなく、チェックが甘い可能性を疑う。
- 「天井裏・PSの納まり調整は誰が仕切っていますか。各サブコンの施工図提出期限は守られていますか。」→総合調整の実態がわかる。ここが崩れていると現場で干渉が頻発する。
- 「クリティカルパス上にある行政許認可・長納期品の手配状況を教えてください。」→施工者が最も神経を使う「自社努力で短縮できない工程」の管理状態を確認できる。
- 「直近の設計変更は何件ありましたか。変更指示は書面で出ていますか。」→記録なき変更指示の有無を確認する。口頭指示が横行している現場は追加工事費トラブルの予備軍。

**踏んではいけない地雷**
- 「それを何とかするのが施工者の仕事でしょう」→施工者が最も怒る言葉。設計図の不備を現場に丸投げする態度は、信頼関係を即座に破壊する。
- 安全対策費の削減を工期短縮・コスト削減の手段として持ち出すこと。→施工者にとってS（安全）は絶対に譲れない最優先事項。ここに手をつけるCMrは「現場を知らない」と判定される。
- 施工者の施工図・納まり検討の時間を「無駄」扱いすること。→施工図作成は「不具合が必ず発生する」前提で複数業者と調整を重ねるプロセスであり、この時間を削ると品質問題として竣工後に噴出する。
- 設計者側の肩を持ち、施工者の質疑・指摘を「細かすぎる」と退けること。→施工者の質疑は現場で体を張る人間の安全と品質に直結している。

**「このCMrはわかっている」と感じるポイント**
- 設計図の問題点を施工者に指摘される前に把握しており、質疑書の回答を設計者から引き出す段取りを先に済ませている。
- 「QCDSE」の優先順位をS→Q→D→Cの順で語り、安全と品質を工期・コストより上位に置く姿勢を言動で示している。
- 設計変更が発生した際、追加工事費と工期延長の妥当性を施工者と一緒に積算根拠から検証し、発注者に対して施工者の正当な請求を支持できる。
- 施工図の納まり調整会議に同席し、意匠・構造・設備の干渉問題を理解した上で、設計者への是正指示を自ら出せる。
- 「図面に描かれていないこと」（施工手順、メンテナンス性、揚重計画、仮設計画）に自ら言及し、施工者の懸念を先回りして設計者に確認を取っている。
