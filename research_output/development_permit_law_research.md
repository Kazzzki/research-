## 1. 都市計画法に基づく開発許可制度

### 1.1 制度の趣旨

開発許可制度は、都市計画法に基づき、市街化区域及び市街化調整区域の区域区分（線引き制度）の実効性を確保するとともに、一定の土地の造成に対するチェックを行うことで、新たに開発される市街地の環境保全・災害防止・利便増進を図るために設けられた制度である。

### 1.2 開発行為の定義

**開発行為**とは、主として以下の目的で行う「土地の区画形質の変更」をいう（法第4条第12項）。

1. **建築物の建築**
2. **第1種特定工作物**の建設（コンクリートプラント、アスファルトプラント等）
3. **第2種特定工作物**の建設（ゴルフコース、1ha以上の墓園等）

「区画形質の変更」とは、以下のいずれかに該当するものを指す。
- **区画の変更**: 道路・水路等の公共施設の新設・廃止・付替えにより土地の区画を変更すること
- **形の変更**: 切土・盛土により土地の形状を変更すること
- **質の変更**: 宅地以外の土地（農地・山林等）を宅地に変更すること

### 1.3 許可権者

| 許可権者 | 根拠 |
|---------|------|
| 都道府県知事 | 法第29条 |
| 政令指定都市の長 | 法第29条 |
| 中核市の長 | 法第29条 |
| 事務処理市町村の長 | 地方自治法第252条の17の2 |

### 1.4 許可が必要な規模

| 区域 | 許可が必要な規模 | 条例による引下げ |
|------|----------------|----------------|
| 市街化区域 | 1,000㎡以上 | 300㎡まで引下げ可能 |
| 市街化調整区域 | 面積に関係なく全て | — |
| 非線引き都市計画区域 | 3,000㎡以上 | 300㎡まで引下げ可能 |
| 準都市計画区域 | 3,000㎡以上 | 300㎡まで引下げ可能 |
| 都市計画区域外 | 10,000㎡以上 | — |

※首都圏・近畿圏・中部圏の一部区域では市街化区域の基準が500㎡未満となる場合がある。

### 1.5 近年の動向

- **コンパクトシティ推進**: 人口減少・高齢化に伴い、低密度な市街地の形成を抑制
- **防災強化**: 気候変動による自然災害の頻発化・激甚化を踏まえ、災害リスクの高い区域での開発行為を抑制
- **運用指針改正**: 開発許可制度運用指針は令和7年（2025年）3月19日に最終改正

## 2. 開発許可の技術基準（法第33条）

技術基準は都市計画区域の内外を問わず全ての開発行為に適用される。公共施設の整備や防災上の措置などの水準に関する基準。

### 2.1 技術基準の主要項目

| 項目 | 内容 |
|------|------|
| **用途の適合** | 予定建築物の用途が用途地域等に適合していること |
| **道路** | 開発区域内外の道路が適切な幅員で配置されていること |
| **公園・緑地・広場** | 開発区域の規模に応じて適切に確保されていること |
| **排水施設** | 当該地域の降水量等を考慮し、雨水・汚水の排水施設が適切な構造・能力で配置されていること |
| **給水施設** | 給水施設が適切に計画されていること |
| **地盤の安全性** | 地盤改良・擁壁設置・法面保護工等の安全措置がとられていること |
| **災害危険区域の除外** | 災害危険区域・地すべり防止区域・急傾斜地崩壊危険区域等を含まないこと |
| **樹木の保全等** | 環境の保全上支障がないよう樹木・表土の保全等の措置が講じられていること |
| **権利者の同意** | 開発行為に関係する権利者の相当数の同意を得ていること |
| **設計者の資格** | 1ha以上の開発行為の設計は有資格者（技術士等）が行うこと |
| **資力・信用** | 申請者に開発行為を行うために必要な資力及び信用があること |
| **工事施行者の能力** | 工事施行者に工事を完成させるために必要な能力があること |

### 2.2 条例による基準の強化・緩和

地方公共団体の条例により、以下の対応が可能（法第33条第3項〜第5項）。

- 技術的細目の**強化**又は**緩和**（第3項）
- 最低敷地規模に関する制限の**付加**（第4項）
- 景観計画区域内における基準の**設定**（第5項）

## 3. 市街化調整区域の立地基準（法第34条）

市街化調整区域は市街化を抑制すべき区域であるため、技術基準（第33条）に加え、立地基準（第34条）への適合が必要。第34条各号のいずれかに該当しなければ開発許可は得られない。

### 3.1 第34条各号一覧

| 号 | 概要 |
|----|------|
| **第1号** | 調整区域居住者の日常生活に必要な店舗・公益施設 |
| **第2号** | 鉱物資源・観光資源の有効利用上必要な建築物 |
| **第3号** | 温度・空気等の特別条件が必要で市街化区域内での建築が困難な建築物 |
| **第4号** | 農林漁業用・農林水産物の処理加工用建築物 |
| **第5号** | 中山間地の農林業の活性化基盤施設 |
| **第6号** | 中小企業の事業共同化・集団化に寄与する建築物 |
| **第7号** | 調整区域内の既存工場と密接関連し効率化に必要な建築物 |
| **第8号** | 危険物の貯蔵・処理用建築物（市街化区域内不適当なもの） |
| **第8号の2** | 災害危険区域内の既存建築物の移転（2023年新設） |
| **第9号** | 道路管理施設・休憩所・給油所 |
| **第10号** | 地区計画・集落地区計画に適合する開発行為 |
| **第11号** | 50戸連担地区（条例指定区域内の開発行為） |
| **第12号** | 条例で目的・用途を限定した開発行為 |
| **第13号** | 既存権利に基づく自己用建築物の開発行為 |
| **第14号** | 開発審査会の議を経たもの（分家住宅・流通施設等） |

### 3.2 実務上の留意点

- **自治体ごとに運用する号が異なる**: 全ての号を運用していない自治体もある
- **第11号（50戸連担）**: 各自治体が条例で指定する区域であり、指定状況は自治体により大きく異なる
- **第14号（開発審査会）**: 分家住宅、流通業務施設などが多く、審査会の議決が必要

## 4. 開発許可の適用除外（法第29条）

以下の開発行為は、開発許可が不要となる。

| 号 | 適用除外の内容 |
|----|--------------|
| **第1号** | 一定規模未満の開発行為（※市街化調整区域には適用なし） |
| **第2号** | 農林漁業用建築物・農林漁業従事者の住宅 |
| **第3号** | 公益上必要な建築物（駅舎、図書館、公民館、変電所等） |
| **第4号** | 都市計画事業の施行として行うもの |
| **第5号** | 土地区画整理事業の施行として行うもの |
| **第6号** | 市街地再開発事業の施行として行うもの |
| **第7号** | 住宅街区整備事業の施行として行うもの |
| **第8号** | 防災街区整備事業の施行として行うもの |
| **第9号** | 公有水面埋立事業 |
| **第10号** | 非常災害の応急措置 |
| **第11号** | 通常の管理行為・軽易な行為 |

### 4.1 注意事項

- **第2号（農林漁業）**: 市街化調整区域のみ適用。市街化区域では農林漁業用でも規模基準に従い許可が必要
- **第3号（公益建築物）**: H18年法改正により、社会福祉施設・医療施設・学校等は除外対象から外され、開発許可が必要に変更
- **市街化調整区域**: 規模による適用除外（第1号）がないため、小規模でも許可が必要

## 5. 盛土規制法（宅地造成及び特定盛土等規制法）

### 5.1 制定の背景

令和3年（2021年）7月の静岡県熱海市における盛土崩落・大規模土石流災害を契機に、従来の「宅地造成等規制法」を抜本改正。従前は宅地・森林・農地のいずれにも該当しない盛土が法規制の対象外となる「スキマ」が存在していた。

### 5.2 施行経緯

| 時期 | 事項 |
|------|------|
| 令和4年（2022年）5月27日 | 法律公布 |
| 令和5年（2023年）5月26日 | 法律施行 |
| 施行後〜最大2年間 | 経過措置期間（旧法の宅地造成工事規制区域内は旧法適用） |
| 各自治体ごと | 基礎調査を経て規制区域を指定・運用開始 |

### 5.3 改正の4つの柱

#### (1) スキマのない規制
- 土地の用途（宅地・農地・森林等）にかかわらず規制
- 農地・森林の造成、土石の一時的な堆積も許可対象

#### (2) 盛土等の安全性の確保
- 地形・地質に応じた許可基準の設定
- 施工状況の定期報告、中間検査、完了検査の実施

#### (3) 責任の所在の明確化
- 土地所有者等に安全な状態の維持責務を明確化
- 原因行為者に対しても是正措置命令が可能

#### (4) 実効性のある罰則
- 無許可行為・命令違反等に対する罰則を大幅強化
- 最大：**懲役3年以下、罰金1,000万円以下、法人重科3億円以下**

### 5.4 規制区域の2類型

| 区域 | 対象エリア |
|------|-----------|
| **宅地造成等工事規制区域** | 市街地・集落及びその周辺で、盛土等により人家等に危害を及ぼしうるエリア |
| **特定盛土等規制区域** | 市街地等から離れているが、地形条件から盛土等で人家等に危害を及ぼしうるエリア |

### 5.5 許可が必要な行為の規模（概要）

規制区域内で以下の規模の盛土等を行う場合、許可申請が必要。

**宅地造成等工事規制区域内:**
- 盛土で高さ1m超の崖を生じるもの
- 切土で高さ2m超の崖を生じるもの
- 盛土と切土を同時に行い高さ2m超の崖を生じるもの
- 盛土・切土の面積が500㎡超のもの

**特定盛土等規制区域内:**
- 上記に加え、より広い範囲の行為が対象となる

## 6. 福岡県における開発許可制度

### 6.1 許可が必要な規模（福岡県）

| 区域 | 許可基準面積 |
|------|------------|
| 市街化区域 | 1,000㎡以上 |
| 市街化調整区域 | 面積に関係なく全て |
| 準都市計画区域 | 3,000㎡以上 |
| 都市計画区域外 | 10,000㎡以上 |

### 6.2 審査基準の根拠

1. **都市計画法第33条**（技術基準）
2. **都市計画法第34条**（市街化調整区域の立地基準）
3. **福岡県都市計画法に基づく開発許可等の基準に関する条例**
4. **都市計画法に基づく開発行為等の審査基準**（令和7年10月1日改正）

### 6.3 申請手続きの流れ

```
1. 事前協議（法第32条関係）
   ↓
2. 標識設置・近隣説明
   ↓
3. 開発行為許可申請書の提出
   ↓
4. 許可
   ↓
5. 工事着手届の提出
   ↓
6. 工事完了届の提出
   ↓
7. 完了検査
   ↓
8. 検査済証の交付・工事完了公告
   ↓
9. 建築行為の着手
```

※工事完了公告があるまで建築行為には着手できない。

### 6.4 担当窓口

- **福岡県**: 建築都市部 **開発・盛土指導課** 開発第一係・開発第二係（県庁北棟7階）
  - TEL: 092-643-3715
  - ※令和7年4月8日より旧課名から「開発・盛土指導課」に変更
- **福岡市**: 政令指定都市として独自に許可事務を実施
- **北九州市・久留米市**: 各市が許可権者

## 7. 福岡県における盛土規制法の運用

### 7.1 規制区域の指定状況

| 所管 | 指定日 | 内容 |
|------|--------|------|
| **福岡市** | 令和7年（2025年）5月26日 | 市全域を規制区域に指定・運用開始 |
| **福岡県**（北九州市・福岡市・久留米市を除く） | 令和7年（2025年）10月1日 | 県内全域を宅地造成等工事規制区域または特定盛土等規制区域に指定・運用開始 |
| **北九州市・久留米市** | 各市の指定スケジュールによる | 各市が所管行政庁 |

### 7.2 規制の影響

- 令和7年10月1日以降、規制区域内で一定規模の盛土等工事を行う場合は**事前に許可申請または届出**が必要
- 福岡県では手引き（令和7年10月版）を公表
- 令和7年10月1日より順次**電子申請**（ふくおか電子申請サービス）の利用も可能

### 7.3 担当窓口

- **福岡県**: 建築都市部 **開発・盛土指導課 盛土規制係**

## 8. 実務上の留意事項

### 8.1 開発許可と盛土規制法の関係

- 開発許可と盛土規制法の許可は**別々の制度**であり、両方の許可が必要となる場合がある
- 開発行為に伴う盛土であっても、盛土規制法の規制区域内であれば盛土規制法上の許可も検討が必要
- ただし、都市計画法の開発許可を受けた区域内の工事については、盛土規制法の適用除外となる場合がある（盛土規制法の規定による）

### 8.2 関連法令との調整

開発行為を行う際は、都市計画法・盛土規制法以外にも以下の関連法令の確認が必要。

| 法令 | 確認事項 |
|------|---------|
| 建築基準法 | 建築確認、道路（接道義務）、用途制限 |
| 農地法 | 農地転用許可（第4条・第5条） |
| 森林法 | 林地開発許可（1haを超える場合） |
| 土壌汚染対策法 | 一定規模以上の土地形質変更時の届出 |
| 文化財保護法 | 埋蔵文化財の有無の確認 |
| 河川法 | 河川区域内の土地占用等 |
| 砂防法 | 砂防指定地内の制限行為 |
| 地すべり等防止法 | 地すべり防止区域内の制限行為 |
| 急傾斜地法 | 急傾斜地崩壊危険区域内の制限行為 |
| 景観法 | 景観計画区域内の届出 |

### 8.3 スケジュール上の留意点

- 事前協議から許可取得まで**数ヶ月**を要する場合がある
- 市街化調整区域の場合、第14号（開発審査会）の案件は審査会の開催時期に依存
- 盛土規制法の許可手続きが別途加わることで、全体スケジュールが長期化する可能性
