## 1. 開発区域の定義と地番の関係

### 結論

**開発区域は図面上の境界線（ポリゴン）で定義されるものであり、登記上の地番（筆界）と一致する必要は法律上ない。**

### 法的根拠

都市計画法第4条第13項：
> 「開発区域とは、開発行為をする土地の区域をいう。」

この定義は「地番」「筆界」への言及を一切含んでいない。開発区域はあくまで**土地の利用範囲**として図面上で画定されるものである。

さらに、京都市の開発許可等審査基準では「土地の区画の変更」を「土地の利用範囲の変更（単なる分合筆のみを目的としたいわゆる権利区画の変更は含まない。）」と定義しており、**登記上の筆界と都市計画法上の「区画」は異なる概念**であることが明確にされている。

したがって、**開発工事は原則として分筆なしで可能**である。

## 2. 分筆が必要なケースと不要なケースの法的整理

### 一言で言うと

**「一筆（ひとつの地番）の土地の"一部分だけ"を新たな開発区域にしようとするときに分筆が必要になる。」**

通常の開発が分筆なしで進められるのは、一筆全体または複数筆をまるごと一つの開発区域にしているからである。

### まとめ表

| ケース | 地番との関係 | 分筆 |
|--------|------------|------|
| 通常の開発（初めての開発） | 一筆全体 or 複数筆まるごと開発区域 | **不要** |
| 今回のケース（既存許可済＋新規申請） | 一筆の一部が既に別の許可で完了済み | **必要** |
| 一筆の一部だけに許可申請（初めてでも） | 同一地番内に開発しない部分が残る | **必要になる場合あり** |

## 3. 開発区域の3つのパターン（図解）

### パターン1：通常の開発（分筆不要）

一筆まるごと or 複数筆まるごとが開発区域。

```
┌───────────┐     ┌────┬────┐
│   開発区域    │  or  │ A筆 │ B筆 │
│   ＝ A筆全体  │     │     └─── ↑ 全部まとめて
└───────────┘     └──────────┘  一つの開発区域
```

→ 地番全体＝開発区域なので矛盾なし → **分筆不要**

### パターン2：既存許可済み＋新規申請（分筆が必要）

同一地番の中に「済み」と「新規」が混在。

```
┌─────────────────────────┐
│           A筆（一つの地番）          │
├────────────┬────────────┤
│ 第1回開発許可済  │  今回の開発区域   │
│ 工事完了公告済   │  （申請したい）   │
└────────────┴────────────┘
```

→ 同じ地番に2つの異なる開発許可が混在 → **法的に不明確**

↓ 分筆する

```
┌────────────┐  ┌────────────┐
│  A-1筆（既存）  │  │  A-2筆（新規）  │
│ 第1回許可済     │  │ 第2回許可申請   │
└────────────┘  └────────────┘
```

→ それぞれの地番に対応する許可が明確 → **問題なし**

### パターン3：一筆の一部だけに初めて開発申請（分筆が必要になる場合あり）

```
┌─────────────────────────┐
│           A筆（一つの地番）          │
├────────────┬────────────┤
│ 開発しない部分   │  開発区域       │
│ （農地のまま等） │  （申請したい）   │
└────────────┴────────────┘
```

→ 法42条の制限範囲が不明確になるリスク → **分筆を求められる場合あり**

## 4. なぜ「一筆の一部だけ」だと問題が起きるのか

3つの法的理由がある。

### ① 開発登録簿の管理上の問題（法第47条）

開発許可が下りると行政は**開発登録簿**に記録・管理する（法第46条・第47条）。この登録は**地番ベース**で行われる。

開発許可を受けた開発区域内では、予定建築物等以外の建築物や特定工作物の新築・改築・用途変更をする際には、あらかじめ都道府県知事等の許可を受ける必要がある（**都市計画法第42条**）。

同一地番に2つの許可が混在すると、**第42条の制限がどの範囲に及ぶのかが不明確になる**。

### ② 工事完了公告の効力範囲の問題（法第37条）

開発許可を受けた開発区域内の土地においては、**工事完了の公告があるまでの間は、原則として建築物等を建築することができない**（**都市計画法第37条**）。

この制限は開発許可を受けた事業主のみでなく、**何人も**建築又は特定工作物を建設してはならないとされている。

既存許可の完了公告が同一地番のまま残っていると、新規許可を取った区域に対してもこの制限が絡んでくる**解釈上のリスク**が生じる。

### ③ 予定建築物の用途制限の衝突（法第42条）

既存の開発許可には「予定建築物の用途」が設定されている。同一地番のまま新たな許可を重ねると、**用途が異なる場合に前後の許可の関係が法的に不明確になる**。

### 法的整理の構造

```
A筆（一つの地番）
├── [西側] 第1回開発許可 → 完了公告済（法36条）
│         └── 法42条の制限が「A筆の開発区域内」に発生中
└── [東側] 第2回開発許可 → 新規申請しようとしている
          └── 法42条の制限を「同じA筆のどこ」に適用するか？
```

**発生する法的矛盾:**
- 法42条・法47条は開発区域を地番単位で管理・公示する仕組みを前提にしているが、同一地番に複数の開発許可が重なると**どの許可の制限がどの範囲に及ぶのか特定不能**になる
- 第2回許可の申請書（法30条）に記載する「開発区域の区域」が、既存の完了済み区域と同一地番上で混在するため、**行政審査上も区域の同一性・独立性を証明できない**

### 分筆の法的機能：「区域の特定」と「効力範囲の明確化」

分筆（不動産登記法に基づく土地表題変更）を行うことで以下が達成される。

```
分筆後：
A-1筆（地番：○○-1）  ←→  第1回開発許可（完了公告済）
    法42条の制限の対象範囲 = A-1筆の開発区域　と明確に対応

A-2筆（地番：○○-2）  ←→  第2回開発許可（新規申請）
    法42条の制限の対象範囲 = A-2筆の開発区域　と明確に対応
```

**法的に達成されること:**
1. **特定性の確保**: 法30条の申請書に記載する「開発区域の区域」が地番として一義的に特定される
2. **効力範囲の分離**: 法42条の建築制限・法47条の開発登録簿の管理が、許可ごとに独立した地番に紐づいて機能する
3. **第三者への公示**: 登記という公示制度を通じて、「この土地には第2回の開発許可がある」という情報が第三者にも明確になる

### 一行で言うと

> **「開発許可の法的効力（法37条・42条・47条）が『開発区域』に紐づいて発生する以上、複数の許可が同一地番に重なれば区域の特定が不能になる。分筆は、その矛盾を登記制度によって解消し、各許可の効力範囲を法的に独立させる手続きである。」**

## 5. なぜ再度開発申請を行う必要があるのか

### 5.1 「開発行為」に該当する行為の定義（法第4条第12項）

開発行為とは、建築物の建築等を目的とした「土地の区画形質の変更」であり、以下のいずれかに該当すれば開発行為となる。

| 変更の種類 | 内容 | 今回のケースとの関係 |
|-----------|------|-------------------|
| **区画の変更** | 公共施設の新設・改廃を伴う土地区画の変更 | 新たな道路等の整備を伴う場合に該当 |
| **形の変更** | 切土・盛土による土地形状の変更 | **盛土工事はこれに直接該当** |
| **質の変更** | 農地等から宅地への地目変更 | **地目変更はこれに直接該当** |

### 5.2 完了公告後の盛土・地目変更が再度の開発許可を要する法的根拠

1. **完了公告後は別の開発行為**: 第1回の開発許可に基づく完了公告（法第36条）が済んだ後、新たに盛土・地目変更を行うことは、第1回許可の範囲外の行為であり、**新たな開発行為**として法第29条の許可が必要
2. **変更許可（法第35条の2）は完了公告前のみ**: 法第35条の2に基づく変更許可は「開発許可後で、かつ、完了公告前の変更」のみが対象。完了公告後の変更は変更許可の適用外
3. **法第42条の制限**: 完了公告後の開発区域内では、予定建築物以外の建築は知事の許可が必要（法第42条）。新たな用途・規模の建築物を建てるには、この制限をクリアする必要がある

### 5.3 再申請が不要なケース

以下の場合は、再度の開発許可が不要となる可能性がある。

| 条件 | 根拠 |
|------|------|
| 盛土の規模が「形の変更」の基準未満 | 各自治体の審査基準（例: 高さ50cm未満等） |
| 地目変更を伴わず、既に宅地 | 「質の変更」に該当しない |
| 建築物の建築を目的としない造成 | 法第4条第12項の「目的」要件を満たさない |
| 市街化区域で面積1,000㎡未満 | 法第29条第1項第1号（規模除外） |
| 法第42条第1項ただし書の許可を取得 | 用途地域が定められている場合、または知事許可 |

## 6. 開発区域を変えるメリットと判断材料

### 6.1 開発区域を再設定する（新規許可を取り直す）メリット

| メリット | 法的根拠・実務上の効果 |
|---------|---------------------|
| **法42条の制限範囲を明確に再定義** | 新たな予定建築物の用途を設定でき、将来の建築の自由度が上がる |
| **盛土規制法のみなし許可が使える** | 都市計画法の開発許可を受けた工事は、盛土規制法の許可を受けたものとみなされる（みなし許可）。開発許可なしで盛土だけ行うと、盛土規制法の独立した許可が別途必要 |
| **開発登録簿の整理** | 新旧の許可が混在する状態を解消し、第三者への公示が明確になる |
| **技術基準への適合を改めて確認** | 排水・擁壁・地盤安全性等が最新基準で審査され、将来の瑕疵リスクが軽減される |
| **敷地の法的地位の一本化** | 分筆後の新地番に対して単一の開発許可が紐づき、管理がシンプルになる |

### 6.2 開発区域を変えない（法42条ただし書許可で対応する）選択肢

| 項目 | 内容 |
|------|------|
| **条件** | 用途地域が定められている場合は法42条の制限自体がかからない。用途地域がない場合は知事の許可が必要 |
| **メリット** | 開発許可の再取得に比べ手続きが簡素・期間が短い |
| **デメリット** | 盛土規制法のみなし許可が使えない（別途許可が必要）。技術基準による安全確認が行われない |
| **適用場面** | 小規模な用途変更・軽微な改築など、大規模な造成を伴わないケース |

### 6.3 判断フロー

```
完了公告済みの開発区域で新たな造成（盛土・地目変更）が必要
    │
    ├─ 建築物の建築を目的とするか？
    │   ├─ NO → 開発許可不要（ただし盛土規制法は別途検討）
    │   └─ YES ↓
    │
    ├─ 区画形質の変更に該当するか？
    │   ├─ NO → 開発許可不要
    │   └─ YES ↓
    │
    ├─ 規模が許可基準以上か？（市街化区域:1,000㎡、調整区域:面積不問）
    │   ├─ NO（市街化区域のみ）→ 開発許可不要
    │   └─ YES ↓
    │
    ├─ 同一地番内に既存の開発許可が存在するか？
    │   ├─ NO → 新規開発許可申請
    │   └─ YES ↓
    │
    └─ 分筆して新地番を確定 → 新規開発許可申請
```

## 7. 変更許可（法第35条の2）vs 新規許可の選択

### 7.1 法第35条の2の適用範囲

| 項目 | 内容 |
|------|------|
| **対象時期** | 開発許可後、かつ、**完了公告前**の変更のみ |
| **対象内容** | 開発区域の位置・区域・規模、道路・擁壁の変更、排水放流先の変更等 |
| **同一性の維持** | 当初の開発許可の内容と同一性を失うような大幅な変更は、**新たに開発許可を受けることが必要** |
| **軽微な変更** | 予定建築物等の敷地形状の変更、工事施行者の変更等は届出で足りる |

### 7.2 今回のケースへの適用

**完了公告後**に新たな盛土・地目変更を行うケースでは、法第35条の2の変更許可は**適用外**。したがって:

- **新規の開発許可申請**が必要
- 既存の開発区域とは**別の開発区域**として申請する
- 同一地番内であれば**分筆が前提**

## 8. 盛土規制法との二重規制

### 8.1 開発許可と盛土規制法の関係

| シナリオ | 都市計画法 | 盛土規制法 |
|---------|-----------|-----------|
| 開発許可を取得して盛土工事を行う | 開発許可が必要 | **みなし許可**（別途の許可手続き不要）。ただし標識掲示・定期報告・中間検査は必要 |
| 開発許可なしで盛土工事のみ行う | 不要 | **独立した許可が必要**（規制区域内の場合） |
| 完了公告後に新たな盛土を行う | 新規開発許可が必要な場合あり | 既存のみなし許可の範囲外。**新たな対応が必要** |

### 8.2 福岡県（柳川市含む）の盛土規制法運用状況

| 所管 | 規制開始日 | 対象範囲 |
|------|-----------|---------|
| 福岡県（北九州市・福岡市・久留米市を除く） | **2025年10月1日** | 県内全域を宅地造成等工事規制区域または特定盛土等規制区域に指定 |

柳川市は福岡県の所管区域に含まれるため、**2025年10月1日以降は盛土規制法の規制が適用されている**。

### 8.3 実務上の判断

**開発許可を取得して盛土を行う方が、盛土規制法の「みなし許可」が使えるため手続きが一本化される。** 開発許可なしで盛土だけ行うと、都市計画法と盛土規制法の2つの窓口で別々に手続きする必要が生じ、コスト・期間ともに不利になる。

## 9. 柳川市固有の留意事項

### 9.1 都市計画区域の状況

- 柳川市は**筑後都市圏**に属する（大牟田市・久留米市・八女市等と構成）
- 都市計画区域マスタープラン: 令和3年4月30日告示
- 開発許可の許可権者: **福岡県知事**（柳川市は政令指定都市・中核市ではない）
- 担当窓口: 福岡県 建築都市部 **開発・盛土指導課**（TEL: 092-643-3715）

### 9.2 市街化調整区域の場合の追加要件

柳川市内に市街化調整区域が存在する場合、以下の追加制約が発生する。

- 面積に関係なく**全ての開発行為**に許可が必要（規模除外なし）
- 技術基準（法第33条）に加えて**立地基準（法第34条）**への適合が必要
- 立地基準各号のいずれにも該当しない場合は、開発審査会の議を経る必要がある（第14号）

### 9.3 事前相談の推奨

柳川市の都市計画に関する確認は:
- **柳川市都市計画課**（柳川庁舎）への来庁が必要
- 都市計画に関する証明書: 1部300円
- 開発許可の具体的な相談: **福岡県開発・盛土指導課**に電話予約のうえ来庁
