# Phase 2 構造設計者視点 詳細レポート

> **案件**: オフィス→ホテル コンバージョン（東京都新宿区・RC造8階・延床6,000m2・築40年）
> **作成日**: 2026-03-28
> **ペルソナ**: 構造設計一級建築士（実務経験15年以上）
> **免責**: 本分析はWeb公開情報に基づくスクリーニングであり、実務専門家の判断を代替しません。

## 1. 「嫌な予感」がするポイント一覧

### 1-1. 旧耐震基準 × 用途変更 = 耐震補強が事実上必須

- **根拠**: 築40年 → 1986年頃竣工だが、設計着手は1983〜84年と推定される。新耐震基準（1981年6月1日施行）の過渡期に該当し、旧耐震設計の可能性が高い。確認申請日が1981年5月31日以前であれば旧耐震確定。
- **リスク**: 用途変更（事務所→ホテル＝法別表第1(い)欄特殊建築物）で確認申請が必要（200m2超）。行政から耐震診断・耐震補強を求められる可能性が極めて高い。
- **ペルソナ判断パターン該当**: #4（耐震性能レベルと構造コストのバランス）
- **数値根拠**: RC造の耐震診断費用は概ね2,000〜3,500円/m2。6,000m2で**1,200万〜2,100万円**。ただし既存図面なしの場合、図面復元費用が別途発生し、総額は**2,000万〜4,000万円**に膨らむ可能性がある。耐震補強工事は10万〜30万円/m2で、仮に全面補強なら**6億〜18億円**。部分補強でも**2億〜5億円**が見込まれ、15億円の予算を大きく圧迫する。

### 1-2. 検査済証なし（仮定）= 確認申請の前段階で躓く

- **根拠**: 検査済証がない建物の用途変更は、国交省「既存建築物の現況調査ガイドライン」（2025年4月統合版）に基づく建築基準法適合状況調査が必要。指定確認検査機関による調査→報告→行政判断というプロセスが追加される。
- **リスク**: 適合状況調査で既存不適格ではなく「違反建築物」と判定された場合、是正工事が必要。是正範囲次第では工事費・工期が大幅に増加する。
- **スケジュールインパクト**: 適合状況調査に2〜4ヶ月、耐震診断に2〜3ヶ月、判定委員会審査に1〜2ヶ月。確認申請前だけで**最低6〜9ヶ月**を要する可能性があり、1年以内開業は極めて困難。

### 1-3. 既存図面なし = 構造解析の入力条件が不明

- **根拠**: 構造計算のやり直し（耐震診断含む）には、柱・梁・壁・スラブの断面寸法、配筋情報、コンクリート強度が不可欠。図面なしでは非破壊検査（電磁波レーダー法、X線透過法等）とコンクリートコア抜きによる現地調査が必須。
- **ペルソナ嗅覚シグナル該当**: 「入力条件不足で着手不能→スケジュール遅延」
- **リスク**: 調査費用の増大（図面復元 + 非破壊検査で**1,500万〜3,000万円**程度）。調査結果次第で設計方針が根本から変わるリスク。

### 1-4. 積載荷重の変化（事務所→ホテル客室）

- **根拠**: 建築基準法施行令第85条に基づく積載荷重の比較:
  - 事務所: 2,900N/m2（床用）/ 1,800N/m2（架構用）
  - ホテル客室: 1,800N/m2（床用）/ 1,300N/m2（架構用）
- **一見有利だが**: ホテルには事務所にない重量物が追加される。ユニットバス（約200〜300kg/基）、廊下の仕上げ荷重増、バンケット・レストラン等の共用部は事務所より積載荷重が大きい（店舗相当で2,900〜3,900N/m2）。
- **リスク**: 客室部分は荷重減でも、共用部・設備機械室等で局所的に荷重増。床スラブ・梁の補強が部分的に必要になる可能性がある。

### 1-5. RC造8階のスパン構成が不明 → 客室割付との整合性リスク

- **根拠**: 1980年代のRC造オフィスビルの典型的スパンは6.0m〜7.2m程度。ホテル客室の標準幅は3.6m〜4.5m。スパンが柱割りの整数倍に合わない場合、客室レイアウトに無駄が生じるか、構造体に手を加える大工事となる。
- **ペルソナ判断パターン該当**: #3（RC造のスパンと経済性）、#1（スパン長と応力・たわみ）
- **リスク**: 柱位置が客室計画と合わず、有効客室面積が減少。RevPAR（1室当たり収益）に直結し、事業収支を悪化させる。

### 1-6. 避難経路・防火区画の大幅変更

- **根拠**: 事務所とホテルでは、避難経路（2方向避難の確保）、防火区画（竪穴区画・異種用途区画）、内装制限の要求水準が大きく異なる。ホテルは就寝用途のため、火災時の避難安全性が格段に厳しい。
- **構造との関連**: 防火区画の追加は耐火壁の新設を伴い、構造体への荷重追加・開口部の制限が発生。既存躯体の耐力壁配置との整合が必要。

### 1-7. 設備インフラの根本的な不足

- **根拠**: オフィスの給排水は共用トイレ・給湯室程度だが、ホテルは全客室にバス・トイレ・洗面が必要。給排水の縦管（PS）の増設、電気容量の増加、空調の個別化が必要。
- **構造との関連**: PS新設に伴うスラブ開口、梁貫通が多数発生。既存RC梁への貫通は補強が必要で、位置・径に制約がある（梁せいの1/3以内、梁端から梁せい以上離すなど）。
- **ペルソナ争点マップ該当**: 「vs 設備: 梁せい・床構造がルーティングを制約。梁貫通可否が設備計画のボトルネック」

### 1-8. 前面道路幅員6m × ホテル用途 → 接道・消防車進入路の懸念

- **根拠**: ホテルは不特定多数が利用する特殊建築物。消防法上のはしご車進入（原則幅員6m以上）はギリギリだが、建物高さが31m超の場合（8階×階高3.5m＝28m→微妙）非常用エレベーター設置義務が生じる可能性。また、東京都安全条例による窓先空地・敷地内通路の要件も確認が必要。
- **構造との関連**: 非常用エレベーター追加の場合、エレベーターシャフトの躯体開口・基礎補強が発生。

### 1-9. 予算15億円の妥当性に対する重大な疑義

- **概算コスト積算**:
  | 項目 | 概算金額 |
  |---|---|
  | 適合状況調査・図面復元 | 2,000万〜4,000万円 |
  | 耐震診断（判定委員会含む） | 1,500万〜2,500万円 |
  | 耐震補強工事 | 2億〜5億円 |
  | 内装・設備工事（ホテル化） | 5億〜8億円（坪単価80万〜130万円相当） |
  | 設計・監理費 | 5,000万〜8,000万円 |
  | 諸経費・予備費（10%） | 1億〜1.5億円 |
  | **合計** | **約9.5億〜17億円** |

- **判定**: 耐震補強の程度次第で15億円を超過する可能性が高い。特に耐震補強が大規模になった場合、予算内に収めるにはホテルグレードを大幅に落とすか、客室数を削減する必要がある。

### 1-10. 工期1年以内の開業 → 非現実的

- **概算スケジュール**:
  | フェーズ | 期間 |
  |---|---|
  | 適合状況調査・図面復元 | 3〜4ヶ月 |
  | 耐震診断・判定委員会 | 3〜4ヶ月 |
  | 基本設計・実施設計 | 3〜4ヶ月 |
  | 確認申請（用途変更） | 1〜2ヶ月 |
  | 施工（耐震補強＋内装） | 8〜12ヶ月 |
  | 消防検査・旅館業許可等 | 1〜2ヶ月 |
  | **合計** | **約19〜28ヶ月** |

- **判定**: 一部工程を並行しても最短18ヶ月程度。1年以内開業は**物理的に不可能**に近い。

## 2. 確認すべき事項リスト

### A. 法令・許認可関連
1. **確認済証・検査済証の有無**: 台帳記載事項証明書を新宿区建築指導課で取得
2. **確認申請時の設計図書**: 新宿区の建築確認台帳から確認申請日・設計内容を照合
3. **用途地域・建ぺい率・容積率**: 商業地域であることの確認と、既存不適格の有無
4. **東京都建築安全条例**: 窓先空地（2m以上）、敷地内通路、2方向避難の確認
5. **旅館業法の許可要件**: 新宿区保健所への事前相談（客室面積7m2以上/室等）
6. **消防法**: 消防設備の追加要件（自動火災報知設備、スプリンクラー、誘導灯等）
7. **バリアフリー法**: ホテルはバリアフリー対応義務（エレベーター、車いす対応客室等）
8. **建物高さと日影規制**: 既存不適格の確認

### B. 構造関連
1. **既存躯体の状態調査**: コンクリート圧縮強度（コア抜き）、中性化深さ、鉄筋腐食
2. **耐震診断（第2次診断）**: Is値（構造耐震指標）の算定。Is≧0.6が目標
3. **基礎形式・地盤条件**: 新宿区は地盤が比較的良好だが、支持層深度・液状化リスクの確認
4. **スパン・柱割りの実測**: 客室レイアウトとの整合性確認
5. **スラブ厚・梁せい**: 設備配管貫通の可否判定に必要
6. **既存の増改築履歴**: 確認申請なしの増改築（違反建築）の有無

### C. 設備関連
1. **給排水の既存ルート**: PS位置・管径・汚水処理能力
2. **電気容量**: 受変電設備の容量と増設可否
3. **空調方式**: 個別空調への変更可否（天井高との関連）
4. **エレベーター**: 既存エレベーターの更新・増設の必要性

### D. 事業性関連
1. **新宿区のホテル需給**: 供給過多の可能性
2. **客室数の見込み**: スパン・柱割りから最大客室数を試算
3. **運営形態**: 直営・リース・MC（マネジメントコントラクト）の検討

## 4. 技術基準の補足調査結果

### 4-1. 検査済証なしの建物の用途変更手続き

国交省「既存建築物の現況調査ガイドライン」（2025年4月統合版）に基づき、指定確認検査機関による建築基準法適合状況調査を実施することで、検査済証に代わる適合性の証明が可能。ただし、違反建築物と判定された場合は是正が前提。

**出典**: [国土交通省 - 既存建築物の活用の促進について](https://www.mlit.go.jp/jutakukentiku/jutakukentiku_house_fr_000061.html)

### 4-2. 耐震診断費用の相場

RC造（1,000〜3,000m2）の耐震診断費用は約2,000〜3,500円/m2。図面なしの場合は図面復元費用が別途発生。

**出典**: [日本耐震診断協会 - 耐震診断の料金](https://www.taishin-jsda.jp/price.html)

### 4-3. 耐震補強工事費の相場

RC造の耐震壁増設等の補強工事は約10万〜30万円/m2。ブレース設置の場合は5万〜20万円/m2。

**出典**: [耐震補強工事の費用相場](https://www.yamaichiseikou.com/earthquake-reinforcement/)

### 4-4. 用途変更の確認申請要件

特殊建築物への用途変更で200m2超の場合は確認申請が必要（2019年法改正で100m2→200m2に緩和）。本案件は延床6,000m2で全面コンバージョンのため、確認申請は確実に必要。

**出典**: [用途変更の確認申請](https://saiteki-branding.com/renovation-kakuninshinsei/)

### 4-5. オフィス→ホテルコンバージョンの設計上の課題

客室面積に対する採光面積（1/8以上）がオフィス（1/20以上）より厳しい。開口部不足が大きな問題となる事例が多い。

**出典**: [オフィスビルからホテルへの転換](https://bb-building.net/project/office-hotel.html)

## 5. 総合評価

### リスクレベル: **極めて高い（RED）**

本案件は以下の3つの致命的リスクを抱えている:

1. **工期**: 1年以内開業は物理的に不可能（最短でも18ヶ月以上）
2. **予算**: 耐震補強費次第で15億円を大幅超過する可能性
3. **手続き**: 検査済証なし＋既存図面なしのダブルパンチにより、確認申請の前段階で6〜9ヶ月を要する

### 構造設計者としての提言

1. **最優先**: 確認済証の有無・確認申請年月日を新宿区で即時確認。旧耐震/新耐震の確定が全ての出発点。
2. **次点**: 予備的現地調査（外観・内部目視・簡易計測）を実施し、概略の構造把握とアスベスト含有リスクの確認。
3. **判断ポイント**: 耐震診断のIs値が0.3未満の場合、補強費が予算の過半を占める恐れがあり、**コンバージョンより建替えの方が経済的**となる可能性を検討すべき。
4. **工期については**: 発注者に対し、現実的なスケジュール（開業まで最短24ヶ月）を早期に提示し、期待値の修正を図ることが不可欠。
