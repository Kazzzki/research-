# Phase2-A 詳細レポート: オフィス→ホテル コンバージョン案件（新宿区）

> 免責: 本分析はWeb公開情報に基づくスクリーニングであり、実務専門家の判断を代替しません。

## 案件概要

| 項目 | 内容 |
|---|---|
| 用途 | オフィス→ホテル（コンバージョン） |
| 所在地 | 東京都新宿区 |
| 規模 | 延床6,000m2・地上8階 |
| 構造種別 | RC造（築40年） |
| 予算 | 15億円以内 |
| 工期 | 1年以内に開業 |
| 既存建物 | あり（築40年RC造オフィスビル） |
| 特記事項 | 既存図面なし、検査済証不明（仮定:なし）、旧耐震 |

## 1. 「嫌な予感」がするポイント（嗅覚シグナル照合）

### 1-1. 「三角形」の不成立リスク（コンセプト×予算×法規適合）

**シグナル**: クライアントの要望が矛盾（広い空間＋低予算＋短工期）

本案件は以下の3要素が同時に成立しない可能性が極めて高い。

- **コンセプト**: オフィスからホテルへの用途変更は、給排水・防火区画・避難経路・遮音・客室割りなど根本的な空間再構成を要する。オフィスの典型的なスパン（6〜8m程度）と階高（3.3〜3.6m程度）がホテル客室に適合するかは未確認。
- **予算**: 延床6,000m2に対し15億円は坪単価換算で約82万円/坪。コンバージョンとはいえ、旧耐震の耐震補強費用・設備全面更新・用途変更に伴う法適合改修を含めると、この予算枠は極めてタイト。一般的なホテル新築が坪100〜130万円であることを考えると、耐震補強＋設備全面更新を含むコンバージョンで15億円に収まるかは相当なリスク。
- **法規適合**: 検査済証なし＋旧耐震＋用途変更の三重苦。法12条5項報告（いわゆる「既存不適格調書」）や建築基準法86条の7の遡及適用範囲の確認が必須。

**根拠**: ペルソナの判断パターン3「コンセプト×予算×法規適合の三角形が成立するか検証」に照らし、3つが同時に成立しない典型的なケース。

---

### 1-2. 既存図面なし＝設計の基盤が存在しない

**シグナル**: 敷地条件が厳しい（法規制の複合）

- 既存図面がないということは、構造図・設備図・意匠図の全てが不明。設計に着手する前に、まず既存建物の実測調査（構造体の配筋調査・コンクリート強度試験・鉄筋腐食調査を含む）が必要。
- この調査だけで2〜4ヶ月を要する可能性がある。工期1年以内の中でこの調査期間は致命的。
- 実測調査の結果、想定と異なる構造形式や劣化が判明した場合、設計の根本的なやり直しが発生する。

**根拠**: 判断パターン1「敷地を初めて見たら法規の前に空間体験を考える」が、そもそも既存建物の実態が分からなければ空間の構想すらできない。

---

### 1-3. 旧耐震＝耐震補強の規模が読めない

**シグナル**: 基本設計後に設計条件が変わる可能性

- 1981年以前の旧耐震基準で設計されたRC造建物。用途変更（特殊建築物への変更）に伴い、耐震改修促進法・建築基準法の遡及適用が生じる。
- 耐震診断の結果次第で、補強工法（増し打ち壁・ブレース・制振装置・免震レトロフィット等）の選定が大きく変わり、それに伴い客室レイアウト・内装計画・コストが根本から変動する。
- 耐震補強がファサードや主要空間に影響する場合、ペルソナの判断パターン5「エントランス・ファサード・主要空間を守る」ことが困難になる。

**根拠**: 争点マップ「vs 構造: 開口拡大の要求 vs 安全性・経済性の制約」が、耐震補強によって激化する。

---

### 1-4. 検査済証なし＝確認申請の難航

**シグナル**: 敷地条件が厳しい（法規制の複合）

- 検査済証がない場合、用途変更の確認申請にあたり、特定行政庁との事前協議が長期化する。
- 2014年の国交省通知（技術的助言）により、検査済証がない建物でも法適合状況調査報告書の提出により確認申請の道は開かれたが、調査・報告書作成・審査のプロセスに6ヶ月以上を要することが珍しくない。
- 工期1年以内に開業という制約と、この行政手続きの所要期間は根本的に矛盾する可能性がある。

---

### 1-5. オフィス→ホテルの用途変更に伴う設備全面更新

**シグナル**: 構造・設備との初期調整が後回しになるリスク

- オフィスとホテルでは設備の性格が根本的に異なる。
  - **給排水**: オフィスは共用トイレ・給湯室のみ。ホテルは各客室にバス・トイレ・洗面が必要。既存RC躯体への配管貫通・PS新設が大規模に発生。
  - **空調**: オフィスのセントラル空調→ホテルの個別空調への変更。天井懐の確保が課題。
  - **電気**: 客室ごとのカードキー・照明制御・コンセント増設。幹線容量の見直し。
  - **防災**: 用途変更に伴うスプリンクラー設置義務の可能性。消防同意の再取得。
- 築40年の既存設備は全面更新が前提。既存配管ルートが不明（図面なし）のため、解体後に想定外の状況が発生するリスクが高い。

**根拠**: 争点マップ「vs 設備: 天井高確保 vs 天井懐不足」が、コンバージョンでは新築以上に深刻化する。

---

### 1-6. 工期1年以内の非現実性

**シグナル**: クライアントの要望が矛盾（短工期）

以下の工程を1年以内に完了させることは極めて困難:

| 工程 | 想定所要期間 |
|---|---|
| 既存建物実測調査・耐震診断 | 2〜4ヶ月 |
| 法適合状況調査・報告書作成 | 2〜3ヶ月 |
| 特定行政庁との事前協議 | 1〜3ヶ月 |
| 基本設計 | 2〜3ヶ月 |
| 実施設計 | 3〜4ヶ月 |
| 確認申請・審査 | 1〜2ヶ月 |
| 施工（解体＋補強＋内装＋設備） | 8〜12ヶ月 |
| 検査・引渡し・開業準備 | 1〜2ヶ月 |

合計すると最短でも20ヶ月程度。並行処理を最大限行っても15〜18ヶ月は必要と想定される。1年（12ヶ月）は非現実的。

**根拠**: 判断パターン7「基本設計2〜4割、実施設計6〜8割の工数配分」から逆算しても、設計期間だけで5〜7ヶ月を要し、残り5〜7ヶ月で施工＋行政手続きを完了させることは不可能に近い。

---

### 1-7. コスト主導による設計品質リスク

**シグナル**: 「全体的にグレードを下げてください」と均等削減を要求されるリスク

- 予算がタイトな中で耐震補強費用が膨らんだ場合、ホテルとしての空間の質（エントランス・ロビー・客室の仕上げ）が均等に削られるリスクが高い。
- ホテルは「空間体験」が商品そのものであり、VEで均等削減を行うと事業性そのものが毀損される。

**根拠**: ペルソナの嗅覚シグナル「全体的にグレードを下げてくださいと均等削減を要求される→建築の魂が均等に削られる最悪のVE」に該当。

## 総合所見

本案件は、意匠設計者の視点から見て「三角形（コンセプト×予算×法規適合）」が成立しない可能性が高い案件である。特に以下の3点が致命的:

1. **工期の非現実性**: 既存図面なし・検査済証なし・旧耐震という三重の制約下で、調査→設計→行政手続き→施工→開業を12ヶ月で完了することは、通常のプロセスでは不可能。工期は最低18ヶ月、安全を見れば24ヶ月を想定すべき。

2. **予算の不確実性**: 耐震補強の規模が耐震診断前には確定せず、予算の3〜4割を占める可能性がある補強費用が読めない段階で15億円という上限を設定することは、後工程でのVE圧力を必然的に招く。

3. **行政手続きの不透明性**: 検査済証なし＋用途変更（特殊建築物）という組み合わせは、特定行政庁との協議が長期化する典型パターン。行政側のスタンスを早期に確認しない限り、プロジェクト全体の見通しが立たない。

**推奨アクション**: 設計着手前に、(a) 耐震診断、(b) 法適合状況調査、(c) 特定行政庁との事前相談の3つを先行実施し、プロジェクトの実現可能性を確認するフィージビリティ・スタディを行うべきである。この段階で工期・予算の現実的な見直しを発注者と合意することが、プロジェクト成功の前提条件となる。
